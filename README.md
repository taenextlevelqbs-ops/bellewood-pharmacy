# Bellewood Pharmacy — Website & Administration Demo

A pharmacy-oriented web application and design demonstration.

## Project overview
A responsive website concept with patient-facing content and administrative workflows. The design work encompasses service information, prescription-related intake pathways, multilingual content, and a separate administration experience.

**Important:** This repository is a software demonstration. It does not establish that the system is approved for clinical use, HIPAA compliant, or authorized to process protected health information.

## Engineering focus
- Next.js application architecture and responsive UX.
- Accessible forms and multi-page service navigation.
- Administrative UI and role-aware application patterns.
- Operational considerations for privacy, validation, and secure provider integrations.

## Development
```bash
npm ci
npm run dev
```

Never test with actual patient records, prescriptions, or protected health information. Configure secrets outside version control.
